#Pixelia

Pixelia is a social 2D sandbox game where players can build worlds, collect items, farm, trade, and play together.

## About

Pixelia is a solo-built game project focused on giving players the freedom to create and explore their own worlds.

The project is currently in the prototype stage, with the core gameplay and visual style being developed step by step.

## Features

- Build your own worlds
- Collect and farm items
- Trade with other players
- Chat and social features
- Player customization
- Pixel-art 2D sandbox gameplay
- Player-created worlds
